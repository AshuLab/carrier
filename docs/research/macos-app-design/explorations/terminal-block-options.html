The terminal of an opened call

What opens when you click a line of the log. Today it is a dark block with the command and the output and, since last turn, a Copy button in a footer. Each option below shows the same three calls: one that worked, one that failed, and one with a long output. The Copy button swaps to "Copied" without changing size (the old one jumped). Hover over the blocks in C, click Copy anywhere, and click "Show more" in D.
What the engine gives us for a command: the command, the first and last lines of its output (up to 4096 characters), whether it worked and how long it took. It does not give the folder it ran in or an exit code as a field (a failure only says "Exit code 1" in its text). So the options show only those; anything else would need the backend.
