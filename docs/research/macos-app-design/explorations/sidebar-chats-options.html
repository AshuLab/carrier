The sidebar: Overview, chats, and Carrier apart

Only the sidebar this time. The Overview stays. Chats (conversations you start and throw away) and Carrier (epics the engine runs on its own) must read as two separate things. Each option is a different way to separate them. Switch what is selected and how much there is: the "many" case has 10 chats and 14 epics, which is where most designs break. The window around the sidebar is the one you already have; a chat opens as a full conversation in the centre. All data is invented.
