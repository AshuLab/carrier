Behavior tab: the primary button and the fields

What is in the app now: the primary button is the system's prominent glass, the number fields are black boxes with the system's blue focus ring, and “Unlimited” is a checkbox beside the hours field. Below, options for each. Hover, click and type in them; the fields really take focus, so you see the focus state.

1 · The primary button

“Save and restart”, “Save” and “Add repo” in its three states: normal, hover (move the mouse) and disabled. The other buttons are the plain glass ones.

2 · The number fields

The same row (Check GitHub every, with the unit) in each style, then the focus and the error state of each, side by side. Click into the fields.

3 · “Unlimited” beside the hours

Right now a checkbox that disables the field. Three alternatives.
  • What I would pick: button A (accent with a soft highlight and glow: reads as the one action, keeps the glass feel), fields B (a light pill with no border and the accent ring on focus, instead of a black hole), hours Segmented (“Limit | Unlimited”, the number appears only for Limit).
  • Fields in SwiftUI: a plain text field in my own style (fill, corner radius, @FocusState for the ring), so it behaves like any text field; nothing changes in how the value is read or validated.
