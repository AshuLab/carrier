Carrier.app — proposed design

Refined version: sidebar with Overview and sections, epic detail with inspector (A2), Overview with cards (A4), and Settings and About at the bottom. It is clickable: try the sidebar items, the cards and the buttons at the bottom.
Click: Overview · any epic · Up next · Ready for test · Settings · About

Empty states

One component, used everywhere something has nothing to show yet: icon, a short title and a single line saying what will make it fill up. Neutral, centred in the space. The Review tab of an epic still in ship (sass-blueprint) uses the first one.

Menu bar

The icon is the always-on part. Clicking it opens this menu; “Open window” opens the window above. The epic list in the menu is new: today the menu only has the status line and the controls.
