Overview — what should it hold?

Today the Overview repeats the sidebar: the same epics, grouped the same way. The sidebar already answers “which epics, in what state”. So the Overview should answer things the sidebar cannot: what do I have to do, who is working right now, what happened while I was away, how is the day going, how does time flow across epics, and is Carrier itself healthy. Six concepts, each on its own, then my suggested mix. Switch the situation to see how each holds up.
