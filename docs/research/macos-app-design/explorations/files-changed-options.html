Files changed: options

Today: a plain "7 files · +166 −12" line, then a flat card per session with the full path in one line (directory dim, name normal) and bare +N −N text. It reads as a log: long directories repeat on every row, the numbers do not line up or say how big a change is, and the session card does not say much about what it is. Five directions with the same data; click a session header to fold it, switch the case or the width to stress them.
What the data allows. The engine sends, per session: id, kind (merged or working), title, and per file: path, added, removed, alsoIn. So the app can group by directory or category (it already derives a category from the name), draw a proportion bar from added/removed, and sort. It cannot say which tool call touched a file, and a file's rename or status (new, deleted) is not sent: so no "new" or "deleted" badges unless the engine adds them (a backend ask).
