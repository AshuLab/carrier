The thread rule of a slice and of a group

The same slice, opened, in six treatments of the line that says “these rows belong to this slice”. Hover the rows (or the lane) to see the hover: the fill reaches the line and the line takes the state's colour. The same line is used by “Ran N commands”, so the group inside each box shows it nested. The theme button is for light mode.
  • A is what the app does now, so the others can be compared to it.
  • B and C make the line tell more (where the thread starts, which row hangs from it) at the cost of a little more ink.
  • D drops the line for a panel: calmest at rest, but the log loses the thin edge it has everywhere else, and a nested group would be a panel in a panel.
  • E and F are the quietest at rest (a hairline, dots); E is the one that answers “which thread is this” most strongly on hover.
