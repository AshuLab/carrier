Workspace sources: where the picker comes from

The chip “Choose a workspace…” opens a way to pick, clone or create the folder a session works in. Four sources: a local folder, a GitHub URL (cloned), your GitHub repositories (browsed, cloned when chosen) and a new project (folder + git init). Clones and new projects live in one projects folder, ~/.carrier/chat/projects, that you can change. “Let Carrier watch this repo” is on by default for what comes from GitHub. Three shapes for the picker below; pick one. The states after choosing are the same for all.
A · One popover that drills in
The chip opens a menu: recent folders, the projects folder, then the four sources. Each source drills into its own step inside the same popover, with ‹ Back. Nothing leaves the sentence; the draft stays visible behind it. The same popover idiom as the branch picker.

C · The sentence grows a card of sources
Choosing the chip unfolds a card under the sentence, inside the page: four tiles for the sources, with the recent folders as a list under them. A source opens its form in the same card. No overlay at all; the page has room, and the card can be as tall as the list needs. The sentence and the box slide down.

The projects folder
One folder for everything Carrier’s chat brings onto this Mac: clones go to <owner>/<repo>, new projects to local/<name>, the same layout the session worktrees already use. It is in the config (so it can be changed) and the picker’s footer says where it is. Carrier never deletes anything in it.
Projects folder~/.carrier/chat/projectsChoose…
Where cloned and new projects live. Changing it does not move what is already there; the picker lists what each folder holds.
