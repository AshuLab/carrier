Epic view — the whole epic, every flow (round 7)

Everything decided so far in one page: the header as today, the pipeline centered up to 700 pt with only the state and the step's name, and the sessions as centered identity rows (A1 / D2). Pick a flow to see the whole epic in it. Each flow is one state the engine can put an epic in (queued, running, needs_human by kind, ready_for_test, merged, cancelled); the names and numbers are invented.

Tool calls and thinkingThe chat's work card (ChatToolGroupView): one folded glass line per run, a violet node for each thought and a node per call when opened, a failed call in red, and a shimmer, ring and glow while it is live. The epic's ToolGroupView goes.
Errors and stopsNoticeCard, the one of "This session is asleep": a tile, a title, the detail and the action at the right (Resume). Orange for what needs you, red for what failed; the last element of the feed.
Messages, code, diffsThe chat's markdown, CodeBlockView and file card, unchanged. What stays the epic's own: the session row, the slices card and the result row (Continue in Terminal).
The costThe epic's events come from the engine's harness parser (ExecEvent), not from the chat host: an adapter from them to the chat's ToolGroup and steps, and the epic's transcript views are removed. The look is shared; the data path is not.
