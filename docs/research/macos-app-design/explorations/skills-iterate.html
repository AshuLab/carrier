Skills: the loop, and writing your own

B and F put together, as a single window you can click through. The loop is the screen; a stage's skill is picked inline; “Write a new skill…” opens the sheet over it. Use Jump to to land on each moment, or just click: stages, skill pills, ↺, the buttons. Runs on changes the harness a stage uses (that is the profile's, not edited here).

  • The file is made when you press “Create and open”; the stage only uses it after Save. The sheet writes a normal skill file, and the stage's assignment is a draft like everything else in Settings. Revert undoes the assignment and leaves the file alone (it is yours).
  • The solve skills are read-only. The way to change one is “A copy of solve's…”, so an update to solve never overwrites someone's edits and the user never edits what Carrier ships with.
  • Which harnesses get a copy: the one this stage runs on is always on; the other is optional. That is what makes the “wrong harness” case rare for skills written here.
  • Checks are the engine's. It reads the folders (the app never does), through the same request that fills the picker, and carrier doctor runs the same checks. “Found for Claude Code” means the harness will see it; nothing says what the skill does.
  • A blank skill gets a warning, not a block. If the file is still only the template's comments the row says so in orange; Carrier does not judge more than that.
