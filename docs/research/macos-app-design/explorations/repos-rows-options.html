Repos: how each row could look

What the app has now: a grey dot, the full name in one weight, one grey line (“Not checked yet · no epics”) and a plain ✕. The options below add the GitHub mark, the owner apart from the name, the folder path, the status as something you can read at a glance, epics as chips, and a better way to take a repo out. The state bar changes what the rows say. Hover over the rows.
