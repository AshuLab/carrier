Work card — always collapsed, with its effect

Decided: the card is always one collapsed line, live or finished; whoever wants the detail opens it. So the live state has to fit in that one line: what the agent is doing right now (thinking, which command is running, waiting for you), the step count, anything that failed, and a timer. Texts are in English as the app shows them. Pick an effect at the top and play the turn.

Effect

One full turn · live

Press Play.

ShimmerA light sweeps across the live text ("Thinking…", "Running"). Says "alive" without moving anything. Off when the card is not live.
Glow borderA violet highlight runs around the card's edge while it works (amber while it waits for you). Quiet, and visible from far away in a long feed.
TickerWhen the step changes, the line rolls up: the new status slides in from below. It is what makes a collapsed line feel like it is progressing.
✦ twinkleThe spark turns and fades slowly while thinking. Always on; it is the card's icon, not an effect to choose.
The one line, by stateLive: ✦ Thinking… · step 1 · 0:03  /  ◌ Running gh api /events?id=4812 · step 2 · 0:09  /  ● Waiting for your answer · step 3. A failure stays visible as "· 1 failed" in red. Done: Worked · 3 thoughts · 3 commands · 0:09. Commands only: Worked · 3 commands. Thought only: Thought · 0:04. Stopped: ■ Stopped · 3 steps.
Opened by handThe person's choice is kept for that turn, live or finished. A live card that is open shows the last 4 steps and "N earlier steps", so it does not push the feed while the agent works.
Reasoning setting offThe card keeps only the commands: it is today's "Worked" row, and the ✦ steps are not drawn.
Reduce MotionAll four effects stop: the glow border stays still, the shimmer is plain text, the ticker is a plain change, the ✦ does not turn. The state is still told by the icon and the words.
