Providers — an icon, a color and a label per account

Each account (claude, Claude Pro, Claude Teams, Codex…) gets three optional fields. Today Pro and Teams wear the same Claude mark, so a message box, a session row, an answer or a role cannot tell them apart. The color tints the mark (a plain glyph, no tile). Edit one in the first card and watch every place below change. Nothing set = the app looks exactly as it does today.

1 · Settings › Providers › Edit account

Three optional fields in the account editor, under Display name. Icon: the tool's own mark (default), a built-in glyph, or the account's first letter. Color: none or one of eight. Label: short text for tight places; empty falls back to the Display name, then to the account's key.

2 · Message box and its provider panel

The button at the left of the message box shows the mark and, when the account has one, its label before the model. The panel's tabs use the mark and the label. A tooltip keeps the full name. Click a tab to choose; click the button to open or close.

3 · New session

The same button and panel (it is the same message box).

4 · Sidebar session rows

The marks a session has worked with (three at most, then “+n”), now in each account's color. Hover gives the label.

5 · Conversation

A message has no avatar or header, so the mark goes where the app already says who answered: the chip of the footer under an answer (copy, time, model, duration, tokens; on hover, always in view on the last answer), and the banner of a turn that could not continue. The user's bubble does not change. The session is the account chosen in the panel above.

6 · Agents page (roles) and other lists

Wherever an account is named as a chip: roles, Usage, the Archive. Short label; the full name on hover.

7 · Carrier epics: who acted

The round avatar of an epic's session: today a color made from the account's name, with the tool's mark on the corner. With a color set, the disc takes it; the corner keeps the tool's plain mark, or the account's icon when it has one.

What I would decide

On the account, not the toolClaude Pro and Claude Teams are the same tool: the difference only exists on the account. Tools (Claude Code, Codex, Antigravity, the local servers) keep their bundled mark.
Label ≠ Display nameDisplay name stays as it is (up to 60 characters, shown in roomy places). Label is the short tag (up to 12), for tabs, chips and the message box button.
Stored with the accountThree optional keys next to displayName in providers.json (icon, color, label): one place for the engine, the chat and the app, and it travels with the account. It needs the zod schema in src/config/providers.ts, the host's providers reply and the app's decoding to learn them.
Color is a name, not a hexEight names that the app tints for light and dark, so every one stays readable on both and a bad value reads as none. The color tints the mark itself: no tile, no dot. A free color picker can come later.
