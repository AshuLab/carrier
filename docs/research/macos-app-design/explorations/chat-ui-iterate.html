Chat UI, round 2: Sessions home, Archive, New session

Decisions from round 1: the Sessions home is option A (grouped list); the Archive keeps that list; the new-session picker is B (the full one). Changes asked for: Search and Filter as one glass group on the left of the header and only the primary action on the right; Archive with Clear sessions, sort by date or project, and Open / Resume / Delete on hover; and in New session a choice between the base folder and a new worktree, with the branch to start from. The conversation view itself is not part of this round.
